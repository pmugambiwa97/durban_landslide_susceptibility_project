# Tabular Deliverables & Lightweight Reference Geometries

This repository directory is strictly reserved for hosting highly compressed, lightweight dataset components that satisfy open-source transparency requirements without impacting file-size latency.

### Data Schematics:
- **Tabular Data**: `.csv` metrics containing final model validation confusion matrices and cross-validation precision metrics.
- **Vector Networks**: Compact spatial files detailing the targeted eThekwini Municipality transport corridor segments selected for risk-exposure screening.

*Note: In accordance with standard cloud data-engineering protocols, all heavy spatial datasets, multi-gigabyte raster stacks, and raw UNOSAT landslide inventory geometry layers are stored securely within cloud cloud architectures or isolated local directories, bypassing the main repository footprint.*
