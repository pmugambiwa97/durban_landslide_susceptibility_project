# Project Graphics & Media Inventory

This directory serves as the asset repository for hosting crisp, high-resolution diagnostic plots, data flow charts, and geospatial maps that populate the main repository documentation.

### Portfolio Visualizations:
- **Model Accuracy Curves**: Receiver Operating Characteristic (ROC/AUC) evaluation diagnostic plots.
- **Geohazard Probability Distribution**: Side-by-side comparative panels isolating landslide susceptibility zones against localized model confidence standard deviation bounds.
- **Infrastructure Risk Matrix**: Styled transport intersection maps showing landslide path proximity hazards.
