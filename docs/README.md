# Technical Frameworks & Methodology Specifications

This folder contains background documentation, physical equations, and data processing specifications underpinning the research design.

### Included Metadata:
- Methodological breakdowns addressing the choice of Sentinel-1 SAR backscatter amplitude over traditional InSAR phase metrics to mitigate rapid temporal decorrelation during mass wasting geohazard events.
- Mathematical parameters and criteria used to construct regional Quantitative Risk Assessment (QRA) bands for eThekwini municipality transport asset vulnerability matrix screening.
